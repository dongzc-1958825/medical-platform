========================================
    众创医案平台 - 用户操作手册
    版本：V2.19.0
========================================

一、软件概述

众创医案平台是一款专注于医疗健康领域的移动应用，为用户提供：
- AI智能咨询（治疗指导、用药指导、药品问答）
- 医案分享与管理
- 健康数据管理（体检报告、关键信息）
- 专病社区交流
- 超级管理员后台管理

二、运行环境

- 移动端：iOS 12+ / Android 8+ 浏览器
- 桌面端：Chrome / Edge / Safari
- 网络要求：建议 WiFi 或 4G/5G 网络

三、功能操作说明

3.1 用户注册与登录

1. 访问平台首页，点击"登录/注册"
2. 填写真实姓名、身份证号、邮箱、手机号
3. 设置密码（需包含大写字母、数字、特殊字符）
4. 完成注册后自动登录

3.2 AI智能咨询

1. 进入"寻医问药"页面
2. 选择"发起咨询"，填写症状信息（共7个步骤）
3. 完成后提交，获得AI用药指导
4. 可在咨询列表中查看回复

3.3 医案分享

1. 进入"医案分享"页面
2. 点击"发布"按钮
3. 填写医案标题、诊断、症状、治疗方案等
4. 可上传图片或PDF文件
5. 发布后可编辑或删除（仅作者或管理员）

3.4 健康管理

- 关键信息：填写血型、过敏史、慢性病、紧急联系人
- 体检报告：上传PDF格式报告，支持预览和删除

3.5 社区功能

1. 进入"社区生活"
2. 选择专病社区或其他社区
3. 可浏览公告、论坛帖子、讲座等内容

3.6 管理员功能

超级管理员拥有以下权限：
- 用户管理（查看、封禁、删除、修改角色）
- 内容审核
- 举报处理
- 社区管理

四、常见问题

Q：如何查看体检报告？
A：进入"我的"→"体检报告"，点击"查看"即可预览PDF。

Q：如何联系平台？
A：通过平台内消息功能或客服邮箱。
